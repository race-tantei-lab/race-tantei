# レース探偵・モデル探索方法

最終更新: 2026-08-08

この文書は、モデル探索の考え方を固定するためのもの。

## 基本原則

- 「あらかじめ買い方・点数・モデル候補を大量に作り、順番に試して200%未満だったと報告する」ことを主たる探索方法にしない。
- 固定DBを先に解析し、JRA市場が継続的に過小評価・過大評価している構造を発見する。
- 発見対象は、馬単体だけでなく、会場、馬場、距離、頭数、レース番号、オッズ帯、モデルと市場の乖離、近走速度、馬・騎手・厩舎の履歴、券種固有の組合せ構造、それらの相互作用を含む。
- 回収率200%以上を生む再現可能な市場の歪みをデータから抽出し、その歪みを一般化するモデルを組み立てる。
- 買い目の点数・資金配分は、発見されたモデルの出力から決める。買い方パターンの総当たりをモデル探索の中心に置かない。
- 開発データ全体を見てから「3区間すべて200%だった条件」だけを選び、その同じ3区間を再現性証拠として扱ってはならない。これは選択バイアスになる。
- 競馬は季節・開催場・開催時期・馬場状態・番組構成が強く連動するため、末尾の連続期間だけを最終検証に使って季節汎化を判断してはならない。

## 季節対応の検証方式

- 行単位の通常ランダム分割は禁止する。未来のレース結果を使って過去レースを学習する時間漏洩が起きるため。
- 評価日は結果と独立な固定乱数で期間全体から分散抽出し、カレンダー月・季節を均等に含める。
- 現行の固定分割は `config/season-aware-validation.json` を使用する。初期30開催日を除く期間から、各カレンダー月4開催日ずつ、合計48開催日を固定 seed 20260808 で選ぶ。
- 48開催日は春・夏・秋・冬を各12日含み、125会場日、最低5レース選択なら各コース625レース以上を評価できる。
- 各評価日の予測は、その評価日より前に利用可能だった情報だけで生成する。同日結果・未来結果は禁止する。
- 評価日に指定された結果は、モデル発見・ハイパーパラメータ調整・ルール選別には使わない。
- 末尾期間だけのホールドアウトは季節ストレステストとして補助利用してよいが、季節汎化の唯一の完成判定にはしない。

## 開催日・季節特徴量

モデルには以下の事前情報を必須で持たせる。

- calendarYear
- calendarMonth
- dayOfYearSin / dayOfYearCos
- weekOfYearSin / weekOfYearCos
- daysSinceArchiveStart
- JRA資料から取得可能な jraMeetingNumber / jraMeetingDay
- venue × calendarMonth
- venue × season
- 既存の天候・馬場状態・会場・芝/ダート・距離・頭数等との相互作用

年月日そのものをIDとして丸暗記させるのではなく、周期性と経時変化を分離して特徴量化する。

## 正しい探索順序

1. 季節分散評価日を先に固定し、その結果を探索から隔離する。
2. 残る学習・発見データだけを使って、市場確率と実現結果の残差を分析する。
3. 券種別に、市場が繰り返し価格を誤る条件・相互作用を発見する。
4. 発見した歪みを、事前情報だけから判定できるモデルへ一般化する。
5. 歪み発見に使っていない内部検証へ、そのルール・モデル・閾値・配分を固定したまま適用する。
6. 内部検証の結果を見て個別ルールを選び直した場合、その区間はもう検証区間として扱わず、さらに未使用データで再検証する。
7. 各開催日・各会場で最低5レースを選ぶレース選択も、同じ市場歪み予測から決定する。
8. 各コースの必須券種を守り、点数と資金配分はモデル出力に応じて可変にする。
9. 全期間の逐次OOSと、季節分散型の因果的ホールドアウトの両方で再現性を確認する。
10. 全固定条件を同時に満たし、全コースで200%以上を確認した完成物にだけ v16 を付ける。

## 2026-08-08 時点で確認したデータ起点の例

以下は完成モデルではなく、市場歪みが実際に存在することを示す内部分析例。

- 馬連: 小倉・14〜17頭立て・既存OOSモデルのEV順位4〜5位の領域で、開発3区間の100円均等購入ROIが約281.0% / 221.8% / 269.1%。サンプル数は206 / 98 / 138点。
- 馬連: ダート1801〜2200m・公式馬連オッズ600倍以上の領域で、開発3区間の100円均等購入ROIが約210.3% / 221.4% / 311.2%。サンプル数は237 / 202 / 306点。
- 小倉の前者は、開発区間の小倉39開催日のうち32日で、その条件に該当するレースを5レース以上確保できる密度がある。

これらの条件をそのまま後付けルールとして本番採用してはいけない。市場歪みの存在を示す発見として扱い、時系列かつ季節対応で事前学習可能な一般化モデルへ落とし込む。

2026-08-08 の監査では、開発3区間すべてを使って59個の馬連歪みを選別すると、各開催日・各会場5レースの開発精算で200%超を作れた。しかし、前半だけで歪みを発見し、後半を未使用検証にすると回収率は市場控除率付近へ戻った。このため「開発3区間を見て選んだ安定ポケット」は完成モデルの証拠として使用しない。

旧末尾ホールドアウトは2026-05-02〜2026-08-02に偏り、春〜夏しか含まない。今後はこれを季節汎化の唯一の完成判定として使用しない。

## 禁止

- 結果を見てから対象レースを5未満へ削ること。
- 季節分散評価日の結果を探索・ルール選別・閾値調整へ使うこと。
- 通常の行単位ランダム分割で未来結果を過去予測へ混入させること。
- 一部期間だけの200%超を完成と扱うこと。
- 巨大払戻1件だけに依存した構成を完成扱いすること。
- 数字を作るために条件を後付けすること。
- 200%未満の探索物をモデルや v16 と呼ぶこと。
- 同じデータを「歪み発見」と「未使用検証」の両方に使うこと。
