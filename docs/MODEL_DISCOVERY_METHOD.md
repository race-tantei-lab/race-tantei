# レース探偵・モデル探索方法

最終更新: 2026-08-08

この文書は、モデル探索の考え方を固定するためのもの。

## 基本原則

- 「あらかじめ買い方・点数・モデル候補を大量に作り、順番に試して200%未満だったと報告する」ことを主たる探索方法にしない。
- 固定DBを先に解析し、JRA市場が継続的に過小評価・過大評価している構造を発見する。
- 発見対象は、馬単体だけでなく、会場、馬場、距離、頭数、レース番号、オッズ帯、モデルと市場の乖離、近走速度、馬・騎手・厩舎の履歴、券種固有の組合せ構造、それらの相互作用を含む。
- 回収率200%以上を生む再現可能な市場の歪みをデータから抽出し、その歪みを一般化するモデルを組み立てる。
- 買い目の点数・資金配分は、発見されたモデルの出力から決める。買い方パターンの総当たりをモデル探索の中心に置かない。

## 正しい探索順序

1. 固定DBの開発区間だけを使って、市場確率と実現結果の残差を分析する。
2. 券種別に、市場が繰り返し価格を誤る条件・相互作用を発見する。
3. 発見した歪みを、事前情報だけから判定できるモデルへ一般化する。
4. 各開催日・各会場で最低5レースを選ぶレース選択も、同じ市場歪み予測から決定する。
5. 各コースの必須券種を守り、点数と資金配分はモデル出力に応じて可変にする。
6. 時系列OOSで再現性を確認する。同日結果や未来結果は使わない。
7. 開発ゲートを通過したモデルだけ、完全未使用の最終ホールドアウトへ進める。
8. 全固定条件を同時に満たし、全コースで200%以上を確認した完成物にだけ v16 を付ける。

## 2026-08-08 時点で確認したデータ起点の例

以下は完成モデルではなく、市場歪みが実際に存在することを示す内部分析例。

- 馬連: 小倉・14〜17頭立て・既存OOSモデルのEV順位4〜5位の領域で、開発3区間の100円均等購入ROIが約281.0% / 221.8% / 269.1%。サンプル数は206 / 98 / 138点。
- 馬連: ダート1801〜2200m・公式馬連オッズ600倍以上の領域で、開発3区間の100円均等購入ROIが約210.3% / 221.4% / 311.2%。サンプル数は237 / 202 / 306点。
- 小倉の前者は、開発区間の小倉39開催日のうち32日で、その条件に該当するレースを5レース以上確保できる密度がある。

これらの条件をそのまま後付けルールとして本番採用してはいけない。市場歪みの存在を示す発見として扱い、時系列で事前学習可能な一般化モデルへ落とし込む。

## 禁止

- 結果を見てから対象レースを5未満へ削ること。
- 最終ホールドアウトを探索に使うこと。
- 一部期間だけの200%超を完成と扱うこと。
- 巨大払戻1件だけに依存した構成を完成扱いすること。
- 数字を作るために条件を後付けすること。
- 200%未満の探索物をモデルや v16 と呼ぶこと。
