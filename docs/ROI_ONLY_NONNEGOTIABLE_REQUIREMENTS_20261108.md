# レース探偵 — 回収率だけを成果として扱う最優先方針（2026-11-08）

## ユーザーからの明示的な指示・最上位の受入条件

**馬の予測ではない。馬券の実際の回収率を最大化する。**

これまで開発者が1着馬予測的中率・3着以内率・対数損失を「改善成果」として何度も報告したことは、ユーザーの要求から外れていた。**今後この方針を変更・軽視・再解釈してはいけない。**

- 評価・探索・報告の主指標は、同一の購入済み／購入想定馬券と実際のJRA払戻に基づく **回収率（ROI）だけ**。
- 採用必須条件は、**実ROI >= 200%**、**最大単一馬券払戻1件を除いて全賭金を分母に残したROI >= 200%**、さらに**最大1レースの払戻を除いて全賭金を分母に残したROI >= 200%**。過去の補助条件である実的中レース率20%以上も維持するが、回収率に優先させない。
- 基本式：ROI = 全実払戻 / 全賭金 × 100。最大払戻除外ROI = (全実払戻 − 最大実払戻1件) / **元の全賭金** × 100。
- **馬の1着的中率、3着以内率、対数損失、AUC、Brier score、その他の予測品質指標の数字をユーザーに成果として提示しない。** これらは金銭的回収率を上げるための一時的な内部診断に限る。モデル選択もそれらの数字を最終基準にしない。
- モデルの「中身」の研究とは、馬券単位の的中確率、実際の払戻分布と裾の厚さ、オッズに対する期待回収率、レース選択、馬券点数、券種、買い目、配分を含め、**購入前に確定した馬券から得られる実現ROIを高めること**。
- ユーザーは選定レース数、券種、馬券点数、買い目、賭金総額、配分、馬場等の条件を**自由に探索**することを求めている。研究段階で「1日5R、1R2券種、2,000円」など古い固定条件を当然視しない。すべて100円単位等のJRA実購入可能性は維持する。
- 多数のパターンから結果の良いものを後付けで選び、同じ過去の数字を「独立実績」と偽ることを禁止。採用方式は先の期間で決定し、次の期間で変更せず、JRA実払戻と元の全賭金で検証。2026年既知データで再最適化した数字は将来回収率の証明にしない。
- JRA公式の購入前オッズのみを使う。歴史データの最終オッズを実際のT−15オッズであると装わない。未検証・前向き検証不足の方式は本番導入・完成宣言禁止。
- Cloudflare D1制限、既存公開サイト、本番固定済み馬券・履歴の不変性は守る。馬の精度改善実験だけを長時間繰り返して、肝心の回収率の検証を放置しない。
- ユーザーへの報告順は **(1) 同一対象の実投資額 (2) 実払戻総額 (3) 実ROI (4) 最大馬券払戻除外ROI (5) 最大レース払戻除外ROI (6) 年/月/場ごとのばらつき (7) 独立期間の再現性・本番採否**。それらが得られない場合は「ROI未検証・採用候補なし」と簡潔に言う。
- **回収率200%以上は研究の合格条件であり、将来200%を保証できるという意味ではない。** データが示さなければ未達成と報告する。

## 2026-11-08時点の判定

- 2026年払戻モデル: ROI 127.95%、最大払戻1件除外 63.21% → **不採用・本番撤回（PR #327）**。
- 旧モデルの開発期間内ROI 431.65%などは独立した将来検証ではない → **200%達成の証拠として使用不可**。
- 研究PR #333 は0〜12R、1〜64点、63券種サブセット、可変賭金の探索エンジン。**コードのCI成功をROI成功とみなさない**。
- 研究PR #334 等の馬の予測精度研究は本要求に対する成果ではない。再度ユーザーへトップ1的中・対数損失等を前面に出さない。
- 採用可能な最大払戻除外後ROI 200%以上の方式は **まだ実証されていない**。
