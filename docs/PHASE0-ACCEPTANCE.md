# Phase 0 受入基準

以下をすべて満たした時点でPhase 0完了とする。

1. 競馬専用Cloudflare無料アカウント上でWorkerが起動する。
2. `GET /health`が200を返す。
3. JRAのrobots.txtを取得できる。
4. 実在する出馬表ページを`race-entry`と判定できる。
5. 実在する結果ページを`race-result`と判定できる。
6. HTTP拒否、CAPTCHA、アクセス制限を`blocked`またはエラーとして検知できる。
7. 不明なページを正常データとして保存しない。
8. レスポンス本文は保存せず、SHA-256・サイズ・識別結果だけをD1に保存する。
9. 週末Cronが実行され、D1に履歴が残る。
10. 決算探偵の本番環境・DB・Secretに一切変更がない。
