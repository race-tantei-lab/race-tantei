# race-tantei

友人共有用の自動競馬予想サイト「レース探偵（仮）」の開発リポジトリです。

現在は **Phase 1：出馬表・結果・払戻の自動記録パイロット** を進めています。Phase 0でJRA公開ページへの到達性を複数回確認した後、札幌5Rを対象に出馬表・確定着順・払戻を自動解析し、D1へ保存します。

## 現在の自動処理

1. JRA公開ページの到達性・ページ種別を検証
2. 成功3回でPhase 0を検証済みにする
3. 札幌5Rの出馬表・結果・払戻を自動取得
4. 厳格な件数チェックに通ったデータだけD1へ保存
5. スマートフォン向けトップ画面に取得件数とレースを表示
6. 成功後は同じパイロット取得を繰り返さない

## 主なURL

- `/`：スマートフォン向け進捗・取得レース画面
- `/health`：システム全体の稼働確認
- `/phase0/status`：Phase 0検証結果
- `/phase1/status`：Phase 1取得結果

## 環境分離

GitHubの所有、Cloudflare、D1、Worker URL、Secretは決算探偵とは分離しています。ChatGPT連携のため既存GitHubユーザーにこのリポジトリだけの共同管理権限がありますが、競馬用Organizationと本番環境の所有者は競馬用アカウントです。

## ローカル確認

```bash
npm install
npm run check
```

GitHub Actionsでも、mainへの更新ごとに型チェックと単体テストを自動実行します。

## 開発フェーズ

- Phase 0：データ取得成立性の検証
- **Phase 1：開催・出馬表・結果・払戻の自動記録（進行中）**
- Phase 2：予想着順・推定確率モデル
- Phase 3：期待値判定・買い目・金額配分
- Phase 4：成績分析・モデル改善
